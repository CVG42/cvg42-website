## My Contributions

- Created a 4-polytope (4D) system in C++ for basic 4D shapes (5-cell to 600-cell) and for procedural duoprism creation using Schläfli notation. This system was created using linear algebra concepts and graph theory.
- Created and implemented an optimized 4D shape shader, that works along the 4-polytope system. This shader is responsible for the projection and animation of the 4D shapes in a 3D environment.
- Optimized different systems, such as a character indicator tracking system where the player can see where other characters are in the level..
